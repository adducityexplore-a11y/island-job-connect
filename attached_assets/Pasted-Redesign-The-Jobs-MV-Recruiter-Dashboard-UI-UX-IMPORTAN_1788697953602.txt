Redesign The Jobs MV Recruiter Dashboard UI/UX.

IMPORTANT:
The current recruiter dashboard feels too basic, flat and dull.

You ARE allowed to redesign:
- Visual style
- Layout
- Dashboard cards
- Sidebar
- Typography hierarchy
- Spacing
- Icons
- Buttons
- Empty states
- Tables
- Candidate cards
- Job cards
- Mobile navigation

Do NOT change:
- The Jobs MV brand identity
- Existing recruiter authentication
- Existing database relationships
- Existing working recruitment functionality

The goal is to create a PREMIUM, MODERN HOSPITALITY RECRUITMENT DASHBOARD.

It should feel suitable for:

- Luxury resorts
- Hotels
- Guesthouses
- Professional hospitality recruiters
- HR managers

The design should feel closer to a modern SaaS recruitment platform than a basic admin template.

--------------------------------------------------
1. OVERALL DESIGN DIRECTION
--------------------------------------------------

Create a clean, premium and modern recruiter experience.

Use The Jobs MV brand colors but introduce more visual depth.

Primary brand:
Deep navy

Accent:
Warm hospitality-inspired gold / soft yellow

Supporting colors:
Soft blue
Green for positive/hired status
Amber for attention
Soft red for rejected/urgent states
Light neutral backgrounds

Avoid excessive bright colors.

Use a soft off-white/light grey dashboard background instead of large areas of pure white.

Use:
- Rounded cards
- Soft shadows
- Subtle borders
- Clear hierarchy
- Premium iconography
- Better spacing
- Strong typography

Avoid:
- Flat white screens
- Huge empty spaces
- Thin grey outlines everywhere
- Generic admin-template appearance
- Too many identical cards

The interface should feel professional but welcoming.
