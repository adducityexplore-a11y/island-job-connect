IMPROVE THE ICON SYSTEM ACROSS THE EMPLOYER WORKSPACE

Please improve the visual quality and consistency of all icons across The Jobs MV Employer Workspace.

IMPORTANT:

Do NOT change functionality, routes, data, authentication, page structure or existing workflows.

This is a visual refinement of the icon system.

GOAL:

Icons should feel:

- Modern
- Premium
- Simple
- Professional
- Easy to understand
- Consistent
- Suitable for hospitality recruitment

The current icons feel slightly generic and inconsistent in visual weight.

-----------------------------------------
USE ONE ICON SYSTEM
-----------------------------------------

Use one consistent icon library across the entire Employer Workspace.

Prefer:

Lucide Icons

if already available in the project.

Do NOT mix:

Filled icons
Outline icons
Emoji
Different icon libraries
Different stroke styles

Use clean outline icons throughout.

Recommended stroke width:

Approximately 1.75–2px

Keep icons visually balanced.

MAKE HIRING SUPPORT SPECIAL
-----------------------------------------

Hiring Support is a signature The Jobs MV service.

Give its icon a recognizable visual identity.

Use:

Sparkles

or a clean UserSearch icon combined with a subtle sparkle treatment.


Use WARM GOLD for the Hiring Support icon:

#D9A520


This gold treatment should communicate:

"THE JOBS MV IS HELPING YOU."


Do not make every navigation icon gold.

Normal navigation icons should remain neutral/light.

Hiring Support can retain its gold signature.

-----------------------------------------
ICON CONTAINERS
-----------------------------------------

Where icons appear inside cards, use subtle containers.

Recommended:

32–40px rounded square

Very light background

8–10px border radius


For special The Jobs MV services:

Very subtle gold-tinted background

Gold icon


Avoid large circles everywhere.

Use containers only where they improve hierarchy.

-----------------------------------------
BUTTON ICONS
-----------------------------------------

Buttons should use icons only when they improve understanding.

Examples:

[ UserSearch ] Find Candidates For Me →

[ + ] Post a Vacancy

[ UserCheck ] Shortlist

[ CalendarCheck ] Request Interview


Do not put icons on every single text button.

Avoid visual clutter.

-----------------------------------------
MOBILE
-----------------------------------------

Icons must remain clear on mobile.

Minimum touch target:

44px for icon-only interactive controls.


Do not make navigation icons tiny.

Ensure:

Consistent alignment
No overlapping
No cropped icons
No icons too close to text

-----------------------------------------
IMPORTANT

Do not use emojis as interface icons.

Do not use overly decorative icons.

Do not use 3D icons.

Do not use cartoon-style icons.

Do not use different icon families on different pages.

Do not add icons simply to fill empty space.

Every icon must help the user understand an action or section faster.

-----------------------------------------
FINAL VISUAL GOAL

The Employer Workspace should have a recognizable visual system:

DEEP NAVY
Professional platform

WARM IVORY + WHITE
Simple and calm workspace

GOLD
The Jobs MV helping the employer

CLEAN OUTLINE ICONS
Simple, modern actions

The interface should feel premium but extremely easy to understand.

A busy hospitality manager should be able to understand an action from:

ICON + SHORT LABEL

without needing to read a long explanation.
