Improve the existing Recruiter Dashboard for The Jobs MV.

IMPORTANT:
- Keep the current visual design, colors, fonts, sidebar style and overall layout.
- Do not redesign the dashboard from scratch.
- Improve functionality, usability and recruitment workflow.
- Make all pages fully responsive on desktop, tablet and mobile.
- Do not create duplicate pages or duplicate components.
- Use the existing database and authentication structure where possible.
- Preserve all existing working features.
- The goal is to turn this from a basic job-posting dashboard into a practical hospitality recruitment workspace.

CORE RECRUITMENT FLOW:

Post Vacancy
→ Receive Applications
→ Screening
→ Shortlisted
→ Interview
→ Offered
→ Hired / Not Selected

The recruiter should always be able to see where each candidate is in this process.
