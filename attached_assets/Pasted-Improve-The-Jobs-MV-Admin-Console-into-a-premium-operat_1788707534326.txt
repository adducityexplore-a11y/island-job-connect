Improve The Jobs MV Admin Console into a premium, operational control center for the platform.

IMPORTANT:
- Do not rebuild the app from scratch.
- Keep the existing authentication, database structure, routes and working admin functionality.
- Preserve existing employer, vacancy, candidate, application, recruitment and audit data.
- Improve the current Admin Console UI, workflows and usability.
- Make the design visually consistent with The Jobs MV recruiter portal, but slightly more serious and operational.
- Do not add fake data.
- All counts, statuses and alerts must come from real database records.
- Make the entire Admin Console fully responsive on desktop, tablet and mobile.

CORE GOAL:

The Admin Console should help The Jobs MV team answer three questions immediately:

1. What needs attention right now?
2. Which employers, vacancies or candidates need review?
3. Where is the recruitment process slowing down?

The admin console should support our core purpose:

Great talent should never be lost to a slow hiring process.

Right Talent. Right Opportunity. Right Time.
