IMPROVE THE JOB SEEKER / CANDIDATE EXPERIENCE & POSITIONING

I want to improve The Jobs MV candidate-facing experience so job seekers immediately understand that this is NOT just another website where they search through job advertisements.

IMPORTANT:

Do NOT rebuild the candidate platform from scratch.

Do NOT change:
- Existing authentication
- Existing database structure unless required
- Existing job listings
- Existing applications
- Existing Hospitality Passport data
- Existing approved brand identity
- Employer Workspace
- Admin Console

Improve the candidate-facing messaging, navigation, dashboard and user experience around the functionality that already exists.

CORE CANDIDATE VALUE:

The Jobs MV should help candidates:

DISCOVER OPPORTUNITIES
+
BUILD THEIR HOSPITALITY PASSPORT
+
SHOWCASE THEIR EXPERIENCE
+
APPLY FASTER
+
TRACK APPLICATIONS
+
BE DISCOVERED FOR RELEVANT OPPORTUNITIES

The candidate should understand:

"This isn't only somewhere I search for jobs. This is where I build my hospitality career profile and connect with the right opportunities."
